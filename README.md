# 🩺 Medical RAG Chatbot

## Project Overview

Medical RAG Chatbot is an AI-powered question-answering system that uses Retrieval-Augmented Generation (RAG) to answer medical queries using a medical dataset from Kaggle.

The system retrieves relevant information from the dataset and uses a Large Language Model (LLM) to generate accurate and context-aware responses.

---

## Objectives

- Build a domain-specific chatbot.
- Implement Retrieval-Augmented Generation (RAG).
- Perform semantic search using vector embeddings.
- Integrate a Large Language Model.
- Develop a user-friendly Streamlit interface.
